# Личный ассистент юриста в Telegram на Claude Managed Agents

Telegram-бот, «мозг» которого — агент Claude в облаке Anthropic. Умеет:

- **отвечать на вопросы** с поиском в интернете и ссылками на источники;
- **разбирать файлы** (PDF, Word, Excel, CSV, фото) и **присылать готовые** (.docx, .xlsx, .pdf, графики);
- **утренний дайджест** в 8:00 МСК: миграционное право РФ, судебная практика, Казахстан, россияне за рубежом, право РФ, новости, ИИ;
- **мониторинг** по будням в 10:00 и 17:00 МСК: новые акты, законопроекты, практика ВС/КС, Казахстан, правила для россиян за рубежом; дальше — ваши дела, цены, страницы. Пишет только при изменениях;
- **помнить** важное между разговорами (memory store);
- **спрашивать разрешение** кнопками, если хочет сделать что-то сомнительное.

Настройки меняются обычными сообщениями боту: «добавь в дайджест тему …», «следи за делом А40-12345/2026», «перестань следить за …».

## Как это устроено

```
Telegram ──► Cloudflare Worker (посредник) ──► Claude Managed Agents (сессия + песочница + память)
   ▲                 │  ▲                                      │
   └── ответы, файлы ┘  └──── вебхук «агент закончил» ◄────────┘
                                 расписания (дайджест, мониторинг) ──► те же агенты
```

| Где | Что | Файл |
|---|---|---|
| Anthropic | среда (песочница), память, 2 агента (чат и расписание), 2 расписания | `scripts/setup.ts` |
| Cloudflare | Worker-посредник + база D1 (только служебные связи, без переписки и секретов) | `src/`, `schema.sql`, `scripts/deploy.ts` |
| Агент | системный промпт, стартовые сообщения задач, начальная память | `agent/` |
| Настройки | модели, бюджеты, расписание | `config.json` |

У агента **нет ни одного секрета**: токен Telegram и ключ API хранит только посредник. Даже если какая-то веб-страница попытается «уговорить» агента, ключи ему недоступны.

## Что нужно один раз

1. **Ключ Claude API** — [Console → Settings → API Keys](https://platform.claude.com/settings/keys), и положительный баланс в Billing.
2. **Бот в Telegram** — напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, он выдаст токен вида `123456:ABC…`.
3. **Cloudflare** (бесплатно) — [dash.cloudflare.com](https://dash.cloudflare.com):
   - Account ID — на главной странице аккаунта справа (или в адресной строке);
   - API-токен — My Profile → API Tokens → Create Token → шаблон **«Edit Cloudflare Workers»**, и в нём добавьте строку **Account → D1 → Edit**.

Добавьте четыре значения в переменные окружения облачного окружения Claude Code (меню окружения в заголовке сессии → Edit → Environment variables, **не** Network secrets):

```
ASSISTANT_API_KEY=sk-ant-...
TELEGRAM_BOT_TOKEN=123456:ABC...
CLOUDFLARE_API_TOKEN=...
CLOUDFLARE_ACCOUNT_ID=...
```

Ключ Claude специально называется `ASSISTANT_API_KEY`, а не `ANTHROPIC_API_KEY`: иначе облачная сессия Claude Code может начать тратить его на себя.

## Установка

В новой сессии с этим репозиторием достаточно написать «разверни ассистента». Вручную:

```bash
npm ci
npm test
npm run setup     # Anthropic: среда, память, агенты, расписания -> state.json
npm run deploy    # Cloudflare + Telegram -> печатает код привязки
```

Потом:

1. Откройте бота и отправьте `/start <код>` — бот привяжется к вам, остальным будет отвечать «частный бот».
2. Чтобы ответы приходили сразу, а не с задержкой до минуты: [Console → Webhooks](https://platform.claude.com/settings/workspaces/default/webhooks) → Add endpoint, URL `https://…workers.dev/anthropic` (его напечатает deploy), события `session.status_idled`, `session.status_terminated`, `session.budget_reached`, `deployment_run.failed`. Ключ подписи (`whsec_…`) отправьте боту командой `/key whsec_…` — бот сохранит его и удалит сообщение.

`npm run setup` и `npm run deploy` можно запускать повторно: созданное найдётся по `state.json` и обновится. **Память при повторном setup не перезаписывается** — агент мог её дополнить.

## Команды бота

| | |
|---|---|
| `/new` | новый разговор (память сохраняется) |
| `/digest` | дайджест прямо сейчас |
| `/monitor` | проверка мониторинга сейчас |
| `/stop` | остановить текущий ответ |
| `/status` | сколько потрачено в текущем разговоре |
| `/memory` | что агент помнит |
| `/invite`, `/users`, `/remove` | подключить и отключить другие аккаунты (только владелец) |

Ответ (reply) на сообщение дайджеста или мониторинга продолжает именно ту задачу: «подробнее про второй пункт».

## Несколько аккаунтов и семья

Владелец (тот, кто первым отправил `/start <код>`) подключает других командой `/invite`. Бот предложит выбрать:

- **«Мой другой аккаунт»** — тот же юридический ассистент и общая память; доступны дайджест и мониторинг (`/digest`, `/monitor`);
- **«Член семьи»** — отдельный агент «Ассистент — семья» без юридического профиля и **своя память**: заметок владельца он не видит, его разговоры не попадают в память владельца.

Код одноразовый и действует 24 часа: с нового аккаунта нужно отправить боту `/start КОД`. `/users` покажет, кто подключён, `/remove <id>` отключит. Дайджест и мониторинг приходят только владельцу. Каждый разговор ограничен тем же лимитом в $3, а расходы всех пользователей идут с одного баланса Console.

## Деньги

Платите вы Anthropic по факту: токены модели, $10 за 1000 веб-поисков и $0.08 за час активной работы сессии. Цены моделей за 1 млн токенов (вход / выход): Opus 5.5 — $4 / $20, Sonnet 5.5 — $2 / $10, Haiku 5.5 — $0.10 / $0.50.

Защита от перерасхода — жёсткие лимиты в `config.json`: разговор — $3 (потом бот сам начнёт новый), каждый запуск дайджеста и мониторинга — $1.50. Ориентир для расписаний (около 75 запусков в месяц, оценка): на Opus 5.5 — $25–60 в месяц, на Sonnet 5.5 — примерно вдвое меньше, на Haiku 5.5 — несколько долларов, но заметно проще по качеству. Поменять модель расписаний: `scheduled.model` в `config.json` → `npm run setup`. Точный расход видно в Console → Managed Agents → Sessions.

Cloudflare: бесплатного тарифа обычно хватает. Если в логах Worker появится ошибка 1102 (превышен лимит процессора), включите Workers Paid ($5 в месяц).

## Ограничения

- Агент работает **не из России**, а часть российских госсайтов закрыта для зарубежных адресов. При настройке не открывались duma.gov.ru, sozd.duma.gov.ru, government.ru, kremlin.ru, vsrf.ru, ksrf.ru, pravo.gov.ru и мвд.рф. Открывались publication.pravo.gov.ru, kad.arbitr.ru, sudrf.ru, consultant.ru, garant.ru, pravo.ru, rapsinews.ru, regulation.gov.ru, mid.ru и казахстанские adilet.zan.kz, legalacts.egov.kz, gov.kz, zakon.kz. Для закрытых источников агент берёт публикации о них на открытых сайтах и помечает это.
- kad.arbitr.ru защищён от роботов, поэтому мониторинг арбитражных дел может не получать данные. Агент об этом предупредит.
- Голосовые сообщения пока не распознаются. Файлы — до 20 МБ (ограничение Telegram для ботов).
- Песочнице агента открыт весь интернет: это нужно для дайджеста по любым сайтам. Секретов в ней нет, но и персональные данные клиентов в память без нужды лучше не класть.
