# Мониторинг — настройки

Когда: по будням в 10:00 и 17:00 по Москве. Сообщать только о значимых изменениях.
У каждого объекта: id (по нему называется файл снимка monitoring/state/<id>.md), статус (активен / пауза), где проверять и что считать значимым.

## Право и миграция (стартовый набор)

### rf-official-acts — активен
Новые официальные акты РФ об иностранцах и миграции.
Где: publication.pravo.gov.ru — новые федеральные законы, указы Президента, постановления Правительства, приказы МВД. Если не открывается — consultant.ru/legalnews, garant.ru/news.
Ключевые слова: иностранн*, мигра*, гражданств*, патент, разрешение на временное проживание, вид на жительство, въезд, выезд, высылк*, выдворен*, депортац*, контролируемых лиц, трудов* мигрант*.
Значимо: любой новый акт по этим темам — номер, дата, суть, вступление в силу.

### rf-migration-bills — активен
Законопроекты о миграции и гражданстве.
Где: sozd.duma.gov.ru закрыт из-за рубежа — используй regulation.gov.ru (проекты НПА), consultant.ru, garant.ru, pravo.ru, rapsinews.ru, Интерфакс.
Значимо: внесение, принятие в чтениях, одобрение Советом Федерации, подписание.

### rf-court-practice — активен
Практика высших судов по делам иностранцев: выдворение, депортация, неразрешение въезда, нежелательность пребывания, гражданство, патенты, ст. 18.8–18.10 КоАП, реестр контролируемых лиц.
Где: vsrf.ru и ksrf.ru закрыты из-за рубежа — используй consultant.ru, garant.ru, pravo.ru, rapsinews.ru.
Значимо: новые постановления Пленума ВС, обзоры практики, определения ВС и постановления КС по этим темам.

### kz-migration — активен
Казахстан: пребывание иностранцев, трудовая миграция, гражданство, ЕАЭС.
Где: adilet.zan.kz (новые НПА), legalacts.egov.kz (проекты НПА), gov.kz (МВД РК, Минтруда), zakon.kz.
Значимо: новые и изменённые НПА, опубликованные проекты, важные разъяснения ведомств.

### ru-abroad — активен
Россияне за рубежом: правила въезда, визы, ВНЖ, счета, налоговое резидентство.
Где: mid.ru (рекомендации гражданам и консульские новости), сайты миграционных ведомств стран, крупные СМИ.
Значимо: новые ограничения или послабления для граждан РФ в популярных странах.
